Background Image Demonstration

CSS Background Image

This webpage demonstrates how to set a background image using CSS.

The image is repeated horizontally using the background-repeat: repeat-x; property.

The background image remains fixed when the webpage is scrolled using the background-attachment: fixed; property.

Scroll the webpage to observe that the background image remains fixed while the content moves.

CSS provides several properties to control the appearance and position of background images.

Background images can be repeated horizontally, vertically, in both directions, or not repeated at all.

This is a simple Level 2 CSS exercise demonstrating background image properties.
